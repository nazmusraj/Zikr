# Nūr Zikr — Android App & APK Build Guide

This package contains your complete **Nūr Zikr (Liquid Glass Tasbih & Spiritual Tracker)** Android project.

## Option 1: Instant Install on Your Android Phone (No PC Needed)
1. Transfer or open `zikr_tasbih_android_app.html` in **Google Chrome** on your Android device.
2. Tap the **⋮ (three dots)** menu in the top-right corner and select **Add to Home screen**.
3. Launch **Nūr Zikr** directly from your Android home screen in full-screen mode with offline persistence, Web Audio bead/crystal sounds, and Android haptic vibration.

## Option 2: Build a Native `.apk` in Android Studio
1. Extract `NurZikr_Android_Studio_Project.zip` on your computer.
2. Open **Android Studio** and choose **Open** → select the extracted `NurZikrTasbih` folder.
3. Let Gradle sync automatically, then click **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Copy `app/build/outputs/apk/debug/app-debug.apk` to your Android phone and install it.
